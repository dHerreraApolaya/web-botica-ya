# Sonidos de compra

La implementación actual genera tonos originales con Web Audio: dos notas breves al agregar al carrito y tres al confirmar un pedido aprobado. No descarga archivos ni usa dependencias. El cliente puede silenciarlos desde el encabezado. Si el navegador bloquea el audio, la compra continúa normalmente.

Opciones gratuitas para sustituirlos por grabaciones:

- Mixkit: https://mixkit.co/free-sound-effects/notification/ — licencia de efectos gratuitos: https://mixkit.co/license/modal/sfxFree/ (permite proyectos comerciales y personales).
- Pixabay: https://pixabay.com/sound-effects/search/notification/ — condiciones: https://pixabay.com/service/license-summary/ (uso gratuito sujeto a las restricciones de la licencia).

Antes de incorporar una grabación, guardar el enlace del recurso y su licencia específica. Para esta versión no se incorporó ningún audio de terceros.
